# Café SofIA — Prototipo (Clase 5, ADEN)

Este es el código del prototipo navegable de **Café SofIA**, un café dentro de ADEN gestionado por SofIA, una IA agéntica que enseña mientras atiende.

## Archivos

- `index.html` — la estructura de la página (secciones: inicio, menú, chat, desafío).
- `styles.css` — todos los estilos visuales (colores, tipografías, animaciones).
- `script.js` — la lógica: carrito de compras, chat simulado con SofIA, desafío.

## Cómo verlo

Abre `index.html` con doble clic, o desde VS Code con la extensión "Live Server" (clic derecho → "Open with Live Server").

## Estado actual

Esto es un **prototipo visual**: el carrito y el chat funcionan en el navegador, pero no están conectados a una base de datos ni a una IA real todavía. Ese es el siguiente paso del curso, dentro de Claude Code, con la skill `guia-cafe-sofia` (GitHub, Vercel, backend, pagos y panel de administración).

## Identidad de marca

- **Estilo:** vintage, jazz y música de los años 50.
- **Colores:** tonos tierra (marrón, ocre, beige) con acentos en rust, verde oliva y latón.
- **Slogan:** "Café con ritmo, servido por inteligencia."
- **Productos:** Espresso (₡800), Latte (₡1.500), Capuccino (₡2.000).
